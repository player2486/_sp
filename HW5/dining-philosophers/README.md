# 哲學家用餐問題程式說明

## 問題描述

五位哲學家圍坐在圓桌前，每個人面前有一盤義大利麵。相鄰哲學家之間共用一根筷子（共五根）。每位哲學家交替進行思考和吃飯，吃飯時需要同時拿起左右兩根筷子。

### 問題挑戰

- 若所有哲學家同時拿起左手筷子（或右手筷子），就會發生**死結**——大家都在等鄰居放下筷子，永遠吃不到飯。

## 實作方式

### 筷子模型

每根筷子以 `pthread_mutex_t` 表示，哲學家「拿起筷子」就是鎖住 mutex：

```c
pthread_mutex_t chopsticks[NUM_PHILOSOPHERS];
```

### 死結預防：固定鎖定順序

原始寫法（可能死結）：

```c
pthread_mutex_lock(&chopsticks[left]);   // 先拿左手
pthread_mutex_lock(&chopsticks[right]);  // 再拿右手
```

若五人都先拿左手，則每人持有一根筷子且等待右手，形成循環等待 → **死結**。

修正寫法（破壞循環等待）：

```c
int first  = (left  < right) ? left  : right;
int second = (left  < right) ? right : left;

pthread_mutex_lock(&chopsticks[first]);   // 先拿編號小的
pthread_mutex_lock(&chopsticks[second]);  // 再拿編號大的
```

因為所有哲學家都以「編號小 → 編號大」的順序拿筷子，不會形成循環等待鏈。

### 哲學家流程

```
思考 → 餓了 → 拿筷子（小→大順序）→ 吃飯 → 放下筷子 → 重複
```

## 驗證死結預防

程式中刻意在拿起第一根筷子後加入 `usleep(10000)` 延遲，增加所有哲學家同時拿一根筷子的機會。若沒有死結預防策略，這個延遲幾乎必定觸發死結；但使用固定順序後，程式總能順利完成。
