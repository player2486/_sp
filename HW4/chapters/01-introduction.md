# 第一章：系統程式概論

## 什麼是系統程式？

系統程式（System Programming）是指撰寫與電腦硬體和作業系統緊密互動的軟體。與應用程式不同，系統程式專注於管理資源、提供底層服務，以及作為應用程式與硬體之間的橋樑。

### 系統程式的範疇

- **作業系統核心**：管理 CPU、記憶體、裝置的核心軟體
- **編譯器**：將高階語言轉換為機器碼
- **組譯器**：將組合語言轉換為機器碼
- **連結器**：將多個目的檔合併為可執行檔
- **載入器**：將可執行檔載入記憶體
- **驅動程式**：控制硬體裝置
- **系統工具**：檔案管理、行程管理等工具

### 系統程式 vs 應用程式

| 特性 | 系統程式 | 應用程式 |
|------|---------|---------|
| 執行環境 | 核心態 / 使用者態 | 使用者態 |
| 資源存取 | 直接存取硬體 | 透過系統呼叫 |
| 可靠性要求 | 極高 | 較低 |
| 開發語言 | C、C++、Rust、組合語言 | 多樣化 |
| 除錯難度 | 困難 | 相對容易 |

## 為什麼學習系統程式？

1. **深入理解電腦運作原理**：了解 CPU 如何執行指令、記憶體如何管理、檔案如何儲存
2. **寫出高效能的程式**：掌握底層機制，才能寫出高效的應用
3. **系統安全**：許多安全漏洞源自系統程式的缺陷
4. **就業機會**：系統工程師、嵌入式工程師、DevOps 等職位需求穩定

## 系統程式開發環境

典型的開發環境包含：

- **編輯器**：Vim、VS Code、Emacs
- **編譯器**：GCC、Clang、MSVC
- **除錯器**：GDB、LLDB
- **分析工具**：perf、Valgrind、strace
- **版本控制**：Git
